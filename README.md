# Tfk NewTech — PS3HEN

Adaptation de la page principale du projet [nikolaevich23/nikolaevich23.github.io](https://github.com/nikolaevich23/nikolaevich23.github.io), sous licence MIT (voir LICENSE). Les fichiers JavaScript et PS3HEN.p3t proviennent de ce projet. Crédits aux auteurs et contributeurs d'origine.

## Publier sur GitHub Pages

Créer un dépôt public `VOTRE_IDENTIFIANT.github.io` sur GitHub. Ajouter le **contenu** de ce dossier à la racine du dépôt (index.html, ps3hen_v100.js, LICENSE et dossier alt). Dans Settings → Pages, choisir Deploy from a branch, `main`, dossier `/ (root)`. Ouvrir `https://VOTRE_IDENTIFIANT.github.io/` dans le navigateur PS3.

La page principale couvre les versions CEX HFW 4.84 à 4.93. Les fichiers `.p3t` sont servis localement depuis le même domaine. Ce paquet ne contient pas les autres outils, firmwares et pages secondaires du dépôt d'origine.

Test statique effectué sur les références de fichiers. Le déclenchement de HEN doit être vérifié sur une PS3 compatible avant usage en boutique.
